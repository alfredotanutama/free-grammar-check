# Simple Grammar Checker

A lightweight, instant English grammar and spelling checker. No API key needed — powered by the free LanguageTool API.

## ✨ Features

- **Instant Check** — highlights spelling and grammar errors in real-time
- **Contextual Suggestions** — shows fix recommendations per error
- **Fix All** — applies first-choice fixes to all errors in one click
- **Bilingual UI** — switch between Bahasa Indonesia and English
- **No setup needed** — just open the HTML file in your browser

## 🚀 How to Use

Just clone and open `Grammar-checker/grammar_checker.html` in your browser. That's it.

Or via local server:
```bash
cd Grammar-checker
python3 -m http.server 8000
```
Then go to `http://localhost:8000/grammar_checker.html`
