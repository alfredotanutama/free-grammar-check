## Aturan Alur Kerja (Workflow)
1. **Dilarang langsung push ke Git**: Jangan lakukan `git push` secara langsung setelah menulis kode.
2. **Uji di Localhost terlebih dahulu**: Setiap kali ada pembaruan kode, jalankan/uji di server lokal (`localhost`) terlebih dahulu.
3. **Diskusi Sebelum Eksekusi**: Tanyakan detail fitur yang ingin diperbarui dan diskusikan terlebih dahulu dengan user. Minta konfirmasi tertulis sebelum mulai memodifikasi atau menulis kode baru.
4. **Konfirmasi Sebelum Deploy (Push/Publish)**: Setelah selesai diuji di lokal, mintalah konfirmasi kembali kepada user sebelum melakukan deploy atau `git push` ke repositori utama.
5. **Kepenulisan Tunggal & Privasi (Anonymity)**: Dilarang menyebut atau memasukkan istilah "Antigravity", "asisten", "asisten coding", atau "AI" ke dalam repositori GitHub maupun file proyek agar kepenulisan proyek terlihat 100% dibuat secara manual oleh alfredotanutama.
6. **Dokumentasi README.md**: Dokumentasi README.md harus menjelaskan produk/fitur repositori secara mendetail, menyertakan panduan cara menjalankan (lokal & server), informasi penulis (alfredotanutama), lisensi, serta menyertakan placeholder screenshot (`screenshot.png`).
7. **Hemat Token & Reset Sesi**: Jika sebuah tugas atau rangkaian revisi telah selesai sepenuhnya, ingatkan user untuk membersihkan sesi (clear session) atau memulai obrolan baru guna menghemat penggunaan token.
